DeskLine API tester

Poke the backend without Postman. Requests are sent relative (e.g. /tickets) and proxied to the API by the Vite dev server. Open this at http://localhost:5173/api-tester.html.

GET /tickets

List tickets. Filters are optional and combinable.

GET /users

List agents (used to populate the assignee filter).

GET /tickets/:id

Fetch a single ticket with its comments.

PATCH /tickets/:id/status

Update a ticket's status. Resolving stamps resolved_at.

POST /tickets

Create a ticket. Only subject and description are required; priority, assigneeId and slaHours have server defaults. Edit the JSON body below.
